Overview

Abstract

WarpSAC is an off-policy reinforcement-learning framework designed for both CPU-scale and GPU-parallel simulation. It provides JAX and PyTorch backends and supports continuous-control environments spanning MuJoCo, IsaacLab, MJLab, ManiSkill, and related benchmark suites.

Our implementation focuses on the interaction between exploration, replay prioritization, parameter normalization, and scalable updates. The same training interface can be used for standard simulator benchmarks and the Unitree G1 sim-to-real locomotion setup.

Method

One interface, multiple regimes.

WarpSAC is a controlled extension of FlashSAC that separates replay-side exploitation from network-side stabilization. Its main replay component is Sample Weight Decay (SWD): each transition receives an age-dependent sampling weight, so recent, policy-relevant data are sampled more often while older transitions retain a nonzero floor for coverage. SWD changes only the minibatch distribution; it adds no auxiliary network, Bellman target, or loss term.

With a decay horizon Tdecay, the weight decreases with transition age and is normalized across valid entries. Setting decay_step=0 gives every transition the same weight and recovers uniform replay. Because SWD improves how a fixed update budget is allocated rather than relying on data volume, we use it in both CPU-scale and GPU-parallel regimes.

Parameter projection normalization is selected from replay coverage. It renormalizes network parameters after each optimizer step, constraining the effective function class and reducing unstable value extrapolation. This is useful when CPU-scale training has narrow replay coverage, so WarpSAC-L keeps normalization enabled together with clipped double-Q targets. GPU-parallel simulation collects broad, rapidly refreshed data; in this data-abundant regime, the same constraint can restrict value fitting, so WarpSAC-A disables parameter normalization and uses the less conservative single-Q variant.

Getting started

Get Started with WarpSAC Codebase

We provide an easy-to-use implementation of WarpSAC with practical features for scalable off-policy reinforcement-learning research in robotics. The codebase supports JAX and PyTorch backends, automatic environment-specific configuration, CPU and CUDA replay, and the Unitree G1 MJLab sim-to-real setup.

Please check out the WarpSAC GitHub repository for installation instructions, training commands, environment integrations, and configuration options.
